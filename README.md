# Marginalia

Claude Code が加えた変更に、GitHub の PR レビューのようにブラウザから行単位でコメントできるツールです。各コメントへの回答は並行して、リアルタイムに返ってきます。

- **前提を共有する**: コメントごとに、作業中の Claude Code セッションを fork（`claude --resume <id> --fork-session`）して答えます。それまでの会話、設計意図、読んだファイルを踏まえた回答になります。
- **並列に動く**: スレッドごとに別プロセスで動くので、返事を待たずに次々とコメントできます。
- **修正依頼にも対応する**: 「修正を依頼する」にチェックすると Claude がファイルを直します。修正は1件ずつ順番に実行するので、同時に依頼しても壊れません。
- **本体に戻す**: スレッドでのやり取りは、本体セッションで次にプロンプトを送ったときに自動で本体の文脈へ追加されます（`UserPromptSubmit` フック）。スレッド内で方針を変えた場合も本体に伝わります。
- **ローカルで完結する**: サーバーは `127.0.0.1` でだけ待ち受けます。

## 使い方

```sh
bun run build            # dist/marginalia（シングルバイナリ）ができる
cd path/to/your-repo     # Claude Code で作業しているリポジトリ
/path/to/marginalia      # ブラウザが開く
```

1. いつも通り Claude Code で作業します。
2. ブラウザで未コミットの差分（未追跡ファイルを含む）を見ます。
3. 行番号をクリック（Shift+クリックで範囲選択）してコメントします。Ctrl/⌘+Enter で送信できます。
4. 回答がスレッドに流れてきます。スレッド内で返信すれば、同じ fork でやり取りが続きます。
5. 終わったスレッドは「解決」で閉じます（fork のセッションファイルも削除されます）。

オプション:

| オプション | 内容 |
|---|---|
| `--port <n>` | 待ち受けるポート（既定は 4567。使用中なら次の番号を試す） |
| `--session <id>` | 本体セッションを明示する |
| `--no-open` | ブラウザを開かない |

本体セッションは、最初は最新のセッションを仮に選びます。本体でプロンプトを送るとフック経由で自動的に特定されます。画面上部のプルダウンから切り替えることもできます。

## 仕組み

```
ブラウザ ──HTTP/SSE── Marginalia サーバー (Bun) ──spawn── claude -p（スレッドごと）
                              ▲
                              └── UserPromptSubmit フック ◄── ターミナルの本体セッション
```

- **質問**: `--permission-mode dontAsk --allowedTools Read Grep Glob` で起動するので、ファイルは変更できません。ツール一覧は本体と同じままなので、プロンプトキャッシュも効きます。
- **修正**: `Edit` と `Write` も許可し、全体で1本のキューに入れて直列に実行します。
- **反映**: 初回起動時に `.claude/settings.local.json` へフック（`marginalia hook`）を登録します。Marginalia が止まっているときは何もしません。
  - Claude Code を起動した後に初めて登録した場合は、`/hooks` での確認か Claude Code の再起動が必要なことがあります。
- **保存**: データは `.marginalia/` に置き、`.git/info/exclude` に追加します。

## 開発

```sh
bun run dev -- --no-open   # ソースから起動
bun test
bun run build
```
